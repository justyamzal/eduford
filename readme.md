# EduFord - University Website Template

## Overview
**EduFord** is a modern, responsive university website template built with HTML, CSS, JavaScript, and PHP. It's designed for educational institutions looking to establish an online presence with a professional, clean interface.

## Website Structure
The site consists of **5 main pages**:

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Landing page with hero section, course overview, campus facilities, and testimonials |
| About | `about.html` | Information about the university, facilities, and statistics |
| Courses | `course.html` | Showcase of academic programs and courses offered |
| Blog | `blog.html` | News, updates, and articles from the university |
| Contact | `contact.html` | Contact form and location information |

## Key Features
- **Responsive Design** - Mobile-friendly with hamburger menu navigation
- **Modern UI** - Uses Google Fonts (Poppins) and Font Awesome icons
- **Interactive Elements** - JavaScript-powered mobile menu toggle
- **Visual Sections**: Hero banner, course offerings, campus facilities (library, cafeteria, basketball), testimonials, and contact form

## Technology Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP (form handling)
- **External Resources**: Google Fonts - Poppins, Font Awesome 6.4

## Project Structure
```
eduford/
├── index.html          # Home page
├── about.html          # About page
├── course.html         # Courses page
├── blog.html           # Blog page
├── contact.html        # Contact page
├── style.css           # Main stylesheet
├── form-handler.php    # Contact form processor
└── images/             # All images and assets
```

## How to Use
1. Open `index.html` in a web browser
2. Customize content by editing HTML files
3. Modify styling in `style.css`
4. Update `form-handler.php` to handle form submissions

This is a beginner-friendly template demonstrating responsive design, CSS flexbox layouts, and basic PHP form handling.
