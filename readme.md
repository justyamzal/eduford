# EduFord

A modern, responsive university website template built with HTML, CSS, JavaScript, and PHP.

## Pages

| Page | File |
|------|------|
| Home | `index.html` |
| About | `about.html` |
| Courses | `course.html` |
| Blog | `blog.html` |
| Contact | `contact.html` |

## Features

- Responsive design with mobile hamburger menu
- Google Fonts (Poppins) + Font Awesome icons
- CSS flexbox/grid layouts
- JavaScript mobile menu toggle
- PHP contact form handler

## Tech Stack

- HTML5, CSS3, JavaScript
- PHP (form handling)
- Google Fonts, Font Awesome

## Getting Started

1. Open `index.html` in a browser
2. Customize the HTML content
3. Edit `style.css` for styling changes
4. Configure `form-handler.php` for email submissions
